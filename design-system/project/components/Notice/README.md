What the panel says when there is nothing to list, and the quiet line shown when notes cannot be saved.

**Use it** for empty and failed states. **You provide** the sentence, and for an empty list the next step.

- Empty states are an invitation: say what will appear and offer "Add note".
- When the store has a link to share, the empty panel adds a second, quieter line under that: "Send people this page's link and their notes show up here." with "Copy link". One more step, not a second headline.
- A storage failure is a `.note-banner`: one sentence in `cm-pin-paper` on `cm-pin-ink`, fixed in both themes because it sits on the host page. It never blocks the page and never opens a dialog.
- A failure inside an open card or the panel is a quiet line in `cm-err` there, not a banner.
- Say what was lost and what still works. No apology, no error code.
